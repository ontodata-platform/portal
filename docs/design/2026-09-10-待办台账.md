# 管理门户待办台账

> **这是唯一的进度跟踪文档**。每完成一项就更新对应行的"状态"和"完成日期"，并在文末"变更记录"追加一行。
> 详细做法见《2026-09-10-门户实施方案-详细设计.md》，台账"设计章节"列指向其章节号。

## 使用说明

| 规则 | 说明 |
|---|---|
| 状态枚举 | ☐ 未开始 / ◐ 进行中 / ☑ 完成 / ✂ 砍掉 / ⏸ 封存（后端线专用） |
| 更新时机 | 任务完成当天；每周五做一次全量巡检（把过期状态纠正） |
| 完成标准 | "验收"列写明的事项可复现；类型检查/lint/单测全绿 |
| 证据 | 完成时在"验收证据"列补一句结论或截图文件名 |
| 优先级 | P0 该期必须 / P1 应做 / P2 可延（延期的 P1 在巡检时重排期次） |
| 新增事项 | 直接追加到对应期表格末尾，编号顺延（如 A7-1）；跨期的新需求先补设计再入账 |
