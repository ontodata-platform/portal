## 第零部分：全局约定（所有任务共同遵守，先读这节）

### 0.1 代码与组件规范

| 约定 | 内容 |
|---|---|
| 页面 | `src/views/<域>/XxxView.vue`；页面内子区块用同目录 `sections/`（仿 `views/personal/sections/`） |
| 共享组件 | 跨页面复用放 `src/components/<域>/`；一次性组件留在页面文件内 |
| 基础件 | 列表一律用 `ui-kit/OdTable`，页头用 `ui-kit/PageHeader`，空/错/骨架态分别用 `ui-kit/EmptyState / ErrorState / SkeletonList`，禁止各页自绘 |
| 图标 | `@ant-design/icons-vue`，禁止 emoji 作图标 |
| 样式 | 颜色/圆角/间距只引用 `ui-kit/tokens.css` 与 `theme.ts`；新增 token 先加 token 再用；主色 #2563eb 不动 |
| 表格列宽 | 每张 OdTable 必须写 `scroll.x` + 操作列 `fixed:'right'`；编码类列用 `mono` 列样式（A4-1 引入） |
| 状态管理 | 跨页面共享的状态建 Pinia store：`stores/notification.ts`（未读/待办数）、`stores/comparison.ts`（对比栏）、`stores/intent.ts`（问答带入）按需新增；页面私有状态用 `ref` 不进 store |
| 类型 | 所有新数据结构定义在 `src/types/<域>.ts`，API 层与 mock 共用同一类型，禁止 any |

### 0.2 Mock 与契约规范（前端先行的关键机制）

1. **数据单一来源**：所有演示数据集中在 `src/mocks/seed.ts`，按域分组导出；各 `*MockApi.ts` 只做"读取 seed + 状态机推进"，不再自造数据。
2. **时间相对化**：seed 里时间一律用 `daysAgo(n)` / `hoursAgo(n)` 工具生成（放 `src/mocks/seed.ts` 顶部），保证任何时候演示数据都是"最近几天"，不出现陈旧日期。
3. **契约同步写**：凡是 mock 实现的功能，在对应 `src/api/*.ts` 里同步写真实模式的函数骨架 + 注释契约（路径、方法、请求/响应 DTO、错误码），沿用现有 `viaMock(mockCall, realCall)` 双模式。后端启动时按注释直接实现。
4. **分页约定**：列表契约统一 `{ items, total, page, size }`；错误统一 `ApiError`（status/code/traceId/fieldErrors）。
